# AI Recruitment Screening Assistant

An automated AI-powered recruitment assistant designed to streamline the HR CV screening process.

## Features
- Gmail API integration for automatic CV retrieval.
- PDF text extraction and preprocessing.
- Semantic search and vector storage using ChromaDB and Sentence Transformers.
- AI-driven evaluation using OpenRouter / LLMs for structured JSON matching.
- Automated candidate ranking and filtering.
- Interactive web interface built with Streamlit and FastAPI backend.
